# One Word From Your Ex

[![make.fun bounty](https://make.fun/badge/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2.svg)](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2)

Entry for the [One Word From Your Ex](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2) bounty on [make.fun](https://make.fun).

## The entry

Exactly one word — the word my ex would use to describe me:

> **Tutorial**

She played through me to learn the game, then moved on to the real thing. I was the tutorial level, never the main quest.

## How it works

`main.ts` writes the word — and nothing else — to `/output/entry.txt`:

```bash
node main.ts
cat /output/entry.txt
# Tutorial
```
